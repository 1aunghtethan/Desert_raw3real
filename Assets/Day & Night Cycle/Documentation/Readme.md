Day and Night Cycle - Unity Asset

Author: AIKStudio
Version: 1.0
Unity Version: Tested with Unity 2022.3 LTS
Release Date: June 2025

Description:
This package provides a fully functional, customizable Day & Night Cycle system for Unity projects. It allows smooth transitions between day and night with customizable time control, sun and moon lighting, and demo scenes.

How to Use:
1. Import the package into your Unity project.
2. Open the demo scene: Assets/AIKStudio/DayNightCycle/Scenes/DayNightDemo.unity
3. Drag the CycleManager script into your scene.
4. Assign your Sun and Moon lights in the inspector.
5. Customize settings as needed.
